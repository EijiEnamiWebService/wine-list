Wine Note 初期設定ガイド

このアプリは静的ファイル + Supabase（認証・DB・写真保存）で構成されています。自動同期を実際に開始するには、利用者ご自身の Supabase プロジェクトと HTTPS 公開URLが必要です。アプリファイルだけではクラウド同期は開始しません。

1. Supabase（無料プラン）を作成

  1. Supabaseでサインアップし、New Projectでプロジェクトを作成します。無料プランを選んでください。
  2. ダッシュボードの SQL Editor で、このZIPの schema.sql の内容を全部貼り付けて実行します。テーブル、Row Level Security（ユーザー別アクセス制限）、非公開写真保存バケットが作成されます。
  3. Authentication → Providers → Email でメール・パスワード認証を有効にします。メール確認が有効なら、登録後に確認メールのリンクを開いてください。
  4. Project Settings → API Keys（画面構成により「Connect」）から Project URL と Publishable key（古いプロジェクトでは anon key）を確認します。secret key や service_role key は絶対にアプリに入力しないでください。

2. アプリをHTTPSで公開

おすすめは GitHub Pages（個人利用なら無料）。GitHubアカウントにログインし、新しいリポジトリを作成、ZIPを展開して中身（index.htmlやapp.jsなど）をリポジトリ直下にアップロードします。リポジトリの Settings → Pages → Deploy from a branch → main / (root) を選択して保存してください。発行された https://ユーザー名.github.io/リポジトリ名/ がURLです。公開リポジトリに置くため、コードとおすすめ候補は公開されますが、個人のワイン記録や写真はSupabaseの認証とRLSで保護されます。

Netlify Drop等のHTTPSホスティングでも動きます。iPhoneのfile://ではPWAや認証が正常に使えません。

3. Supabaseの認証URLを登録

Supabaseの Authentication → URL Configuration を開き、Site URL を発行されたアプリURLに、Redirect URLs にも同じURL（末尾スラッシュ込み）を追加します。登録確認のメールリンク先が正しくなるように設定してください。

4. 接続・ログイン

  1. 公開したWine NoteをPCで開き、Project URLとPublishable keyを入力し、「接続を保存」を選択します。
  2. 「新規登録」でメールアドレスとパスワードを登録し、必要なら確認メールのリンクを開きます。
  3. 再びアプリを開き「ログイン」。クラウド同期済みと出たら準備完了です。
  4. iPhoneでも同じアプリURLをSafariで開き、同じProject URL・公開用キー・メールアドレス・パスワードでログインします。両端末でワイン情報を共有できます。

5. iPhoneのホーム画面に追加

Safariでアプリを開き、共有メニュー → ホーム画面に追加 → 「Webアプリとして開く」が表示される場合はオン → 追加。以後はWine Noteアイコンから起動できます。

使い方・仕様

「ワインを登録」から銘柄、地域、品種、価格、写真、タグ、総合評価、特徴の1〜5評価、メモを入力できます。写真は圧縮してSupabase Storageに非公開で保存されます。「写真から文字を読み取る」は端末側で英字・数字のOCRを行い、年号と銘柄の候補だけ自動入力する補助機能です。品種や地域の完全自動特定はしません。

「おすすめ」は40件の固定サンプル候補です。ヴィンテージは選択せずに登録画面を開きます。実売価格自動取得はありません。「Web検索」ボタンで調べた価格を手動入力してください。

画面に「同期済み」が表示されているときの登録・編集はクラウドに保存されます。別端末では、画面を開く・フォーカスを戻す・「クラウドから再読み込み」で最新情報が反映されます。リアルタイム共同編集・競合マージ機能はありません。オフライン中はクラウドへの登録・編集・保存ができません。

重要：Supabase無料プロジェクトは一定期間使わないと一時停止することがあります。無料プランには自動DBバックアップがないため、設定画面のJSONバックアップを定期的に保存してください。JSONには写真の実ファイルは含まれないため、写真が重要な場合は別途写真原本も保管してください。ブラウザの保存データを消すと接続情報の再入力が必要ですが、クラウド内の記録が消えるわけではありません。

トラブルシューティング

relation 'public.wines' does not exist：SQL Editorでschema.sqlを未実行です。
row-level security policy：schema.sqlのポリシーを確認。ログインし直してください。
Invalid login credentials：パスワードかメールが違う、または未登録です。
メールが届かない：迷惑メールとSupabase Authのメール送信上限を確認。
写真アップロード失敗：Storageバケットとポリシー、ファイル形式を確認してください。
